# ZUBIRI SmartBanking Lab — GitHub Pages

Demostración educativa de un prototipo de IA para prever la tesorería de una pequeña empresa. **Todos los datos son sintéticos**.

## Publicar en GitHub Pages (sin terminal)

1. Crea un repositorio público, por ejemplo `zubiri-smartBanking-lab`.
2. Abre el ZIP y descomprímelo en tu ordenador.
3. En GitHub, pulsa **Add file → Upload files** y sube **los archivos sueltos** de esta carpeta a la raíz del repositorio. **No subas únicamente el ZIP**.
4. Confirma el commit con **Commit changes**.
5. Ve a **Settings → Pages → Build and deployment**.
6. Selecciona **Deploy from a branch**, rama **main**, carpeta **/(root)** y pulsa **Save**.
7. La URL esperada para el usuario `rbarrenago` sería `https://rbarrenago.github.io/zubiri-finai-lab/` (si se usa exactamente ese nombre y cuenta).

## Archivos

- `index.html`: portada bilingüe; punto de entrada para GitHub Pages.
- `ZUBIRI_FinAI_Lab_Demo_EU.html`: demostrador íntegro en euskera.
- `ZUBIRI_FinAI_Lab_Demo.html`: demostrador íntegro en castellano.
- `.nojekyll`: evita transformaciones de Jekyll no necesarias.

Los HTML son autónomos: no requieren Python, servidor, API, archivos externos ni instalación de dependencias para ejecutarse. Los resultados son ilustrativos y no representan precisión validada en clientes reales.

**Aviso**: el contenido publicado con GitHub Pages es accesible públicamente. No subir datos personales, operaciones bancarias reales ni credenciales.
